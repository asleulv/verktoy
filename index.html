verktøy

brukarverktøy utan sporing

Eit utval av praktiske verktøy for enkle, anonyme og ikkje-innlogga aktivitetar. All databehandling skjer 100% lokalt i din egen nettlesar utan innlogging eller ekstern sporing.

Datakonvertering

Konverter mellom CSV, JSON, Excel og ODS. Filtrer kolonner og vask data før eksport.

Bilde-komprimering

Reduser filstorleiken på bileta dine ved å justere kvalitet og storleik. Alt skjer lokalt.

Tabellvisning

Gjer uoversiktlege datafiler om til tydelege, søkbare tabellar. Støttar CSV, JSON og Excel.

Tekst-rydding

Vask tekst, fjern HTML-taggar eller konverter mellom Markdown og HTML på sekundet.

Prompt-hjelpar

Bygg betre prompts til AI ved å bruke profesjonelle rammeverk. Strukturert for suksess.

Mappe-tre

Få ei fullstendig visuell oversikt over mappestrukturen din. Generer strukturtre på sekundet.

Unix-hjelpar

Få full kontroll på terminalen med ein visuell CHMOD-kalkulator og søkbar oversikt over Unix-kommandoar.

ABL-hjelpar

Søkbart bibliotek for Progress OpenEdge ABL. Finn syntax-eksempel, datatyper og database-kommandoar.

PDF-kvern

Maksimalt personvern for dine dokument. Slå saman, splitt eller slett sider frå PDF-ar rett i nettlesaren.

Liste-vaskar

Sjekk ei CSV-fil mot ei Excel-fil og fjern e-postadresser som finst i båe. Genererer ei rein fil på sekundet.

Excel-splittar

Del opp gigantiske Excel-filer i fleire, handterbare bitar. Vel overskriftsoppførsel og last ned alt i éi ZIP-fil.

JSON-inspektør

Sjekk JSON-data frå API-lenker eller filer på ein ryddig måte. Sjekk struktur, søk i verdiar og utforsk data direkte.

Akkord-hjelpar

Verktøy for transponering og akkord-visning for musikkarbeid og akkordark.
